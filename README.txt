# Map4VO

## Назначение проекта

Map4VO — интерактивная карта маршрутов патрулирования.

Проект предназначен для визуального отображения карты военного округа,
выбора маршрутов и просмотра детализированных фрагментов карты.

## Работа с картой

Основная карта имеет размеры:

8191 × 10011 px

Из-за большого размера карта работает внутри отдельного viewport.

Масштабирование и перемещение выполняются через transform:
translate3d + scale.

SVG overlay масштабируется вместе с основной картой.

## Работа с маршрутами

В текущей версии маршрут представлен объектом DATA:

- id — идентификатор маршрута;
- title — название маршрута;
- points — координаты SVG-полигона;
- file — изображение детального фрагмента.

SVG-полигон используется для выбора маршрута на карте.

При выборе области карты:

1. определяется выбранный сегмент;
2. загружается изображение из cache;
3. открывается окно просмотра;
4. выбранная область подсвечивается.

## Хранилище данных

Проект использует localStorage браузера.

Текущие сохраняемые данные:

Map4VO.view

Содержит:

- масштаб карты;
- координату X;
- координату Y.

В будущих версиях планируется добавление:

- последнего выбранного маршрута;
- настроек интерфейса.

## Правила разработки

### Один модуль — одна ответственность

Каждый блок отвечает только за свою область.

### Одна функция — одна задача

Функция должна выполнять одну логическую операцию.

### CONFIG — единственный источник настроек

Настройки приложения не должны быть разбросаны по коду.

### Не дублировать ответственность

Одна операция должна иметь один источник изменения.

Например:
изменение курсора выполняется только через updateCursor().

### Удалять устаревшую логику

Если новый механизм заменяет старый — старый удаляется.

### Сначала архитектура, потом функциональность

Перед новой возможностью определяется:

- модуль;
- функции;
- состояние;
- события.

### Минимальная рабочая версия

Сначала простое рабочее решение, затем улучшение.

### Каждая версия имеет границы

Новые функции не добавляются после завершения версии.
